Component anatomy notes
Sidebar 168–220px fixed width, --surface-1 background, 0.5px right border. Project rows: 8px colored dot + label, 8px border-radius on hover/active state, active state uses a flat #EFEFEC fill (no border, no shadow).

Kanban card White surface, 0.5px border (2px accent border only for a highlighted/blocked card — this is the one deliberate exception to the 0.5px rule), 8px radius, 8px internal padding. Title 12px regular. Footer row: priority pill left, assignee avatar right, space-between.

Pills / badges 8px border-radius (soft rounded, not a full pill), 10px font, colored background at the "-bg" token with matching "-text" token — never black text on a colored background.

Color rule — the one thing to enforce everywhere Two separate color systems that must never cross: project identity (purple/teal/coral — sidebar dots, calendar tags, gantt bars) tells you which project; semantic status (red/amber/green) tells you urgency or state (priority pills, notifications, overdue markers). A task card's priority pill is never colored by its project, and a project dot is never colored by urgency.
